# 몰입각 토스(앱인토스) 출시 가이드 — 따라 하기만 하면 돼요

**총 걸리는 시간:** 직접 하는 일 약 2~3시간, 그리고 검수 기다리는 시간이 영업일 2~3일.
**규칙:** 한 단계씩 하고, 체크박스(☐)를 하나씩 채워요. "이렇게 보이면 성공"이 안 보이면 다음 단계로 가지 말고 **막히면** 칸을 보세요.
그래도 안 되면 화면을 캡처해서 Claude에게 보내면 돼요.

> ⚠ 표시는 공식 문서를 직접 열어 확인하지 못한 부분이에요(이 작업 환경에서 토스 사이트 접속이 막혀 있었어요).
> 화면에 보이는 안내가 이 문서와 다르면 **화면 안내를 따르세요.**

---

## 0단계. 준비물 (10분)

- [ ] **만 19세 이상, 본인 명의 토스 앱이 깔린 휴대폰** — 콘솔 가입 조건이에요. 중학생이라면 보호자(부모님) 명의로 가입하고, 작업은 같이 하면 돼요.
- [ ] **이메일 주소** — 고객센터 연락처로 써요.
- [ ] **컴퓨터**(Windows 또는 Mac)와 인터넷
- [ ] **이어폰** — 실제 휴대폰 테스트 때 필요해요.
- [ ] **아이폰·안드로이드 중 가능한 만큼** — 둘 다 있으면 좋아요.

---

## 1단계. 컴퓨터 준비 (20분, 처음 한 번만)

**할 일**
1. https://nodejs.org 에 들어가 **LTS** 버튼을 눌러 설치해요. 설치 화면에서는 계속 "다음(Next)"만 누르면 돼요.
2. https://git-scm.com 에서 Git을 설치해요(Mac은 보통 이미 있어요).
3. **터미널**을 열어요.
   - Windows: 시작 메뉴에서 `PowerShell` 검색 → 실행
   - Mac: `Command + Space` → `터미널` 검색 → 실행
4. 아래 두 줄을 한 줄씩 복사해 붙여 넣고 Enter를 눌러요.
   ```bash
   node -v
   git --version
   ```

**이렇게 보이면 성공:** `v22.…`(또는 v20 이상) 같은 숫자와 `git version …`이 나와요.
**막히면:** "명령을 찾을 수 없음"이 나오면 터미널을 껐다가 다시 열어요. 그래도 안 되면 컴퓨터를 재시작해요.

---

## 2단계. 코드 받기 (5분)

**할 일** — 터미널에 한 줄씩:
```bash
git clone https://github.com/typetruelee-lang/study-beat.git
cd study-beat
git checkout claude/hopeful-lamport-lscfpk
npm install
```

**이렇게 보이면 성공:** 마지막에 `added … packages` 같은 문장이 나오고 빨간 `ERR!`이 없어요.
**막히면:** `npm install`에서 오류가 나면 한 번 더 실행해 봐요(인터넷이 잠깐 끊겼을 수 있어요).

> 다음에 다시 할 때는 `cd study-beat` → `git pull` → `npm install` 만 하면 최신 코드가 돼요.

---

## 3단계. 앱인토스 콘솔 가입 (15분)

**할 일**
1. 컴퓨터 브라우저에서 앱인토스 콘솔에 접속해요. (개발자센터 https://developers-apps-in-toss.toss.im 상단 메뉴의 "콘솔")
2. **토스 앱으로 본인 인증**해요. 휴대폰에 알림이 오면 토스 앱에서 확인을 눌러요.
3. 약관에 동의해요.
4. **사업자 인증은 지금은 건너뛰어도 돼요.** 몰입각은 배너 광고를 쓰는데, 광고 수익(예상)이 누적 5천 원이 될 때까지는 사업자 없이 쓸 수 있어요(2026-08-28 유예 정책). 5천 원이 되면 5영업일 안에 사업자 등록을 해야 해요.

**이렇게 보이면 성공:** 콘솔 첫 화면(워크스페이스 만들기 안내)이 보여요.
**막히면:** 만 19세 미만 계정은 가입이 안 돼요 → 보호자 계정으로 해요.

---

## 4단계. 워크스페이스 만들기 (2분)

**할 일:** "워크스페이스 만들기" → 이름에 `몰입각팀` 입력 → 만들기.
(워크스페이스는 앱을 담는 폴더 같은 거예요. 이름은 나중에 바꿀 수 있어요.)

**이렇게 보이면 성공:** 워크스페이스 화면에 "앱 등록" 같은 버튼이 보여요.

---

## 5단계. 앱 등록 (30분)

**할 일:** "앱 등록"을 누르고, 컴퓨터의 `study-beat/store-assets/console-text.md` 파일을 열어서 칸마다 복사·붙여넣기 해요.

- [ ] **앱 ID(appName)**: `molip-gak` ← **한 번 정하면 영원히 못 바꿔요.** 붙여 넣은 뒤 글자를 하나씩 확인해요(엠·오·엘·아이·피·하이픈·지·에이·케이).
- [ ] **앱 이름**: `몰입각` ← 앱 화면 제목과 같아야 해요(다르면 반려).
- [ ] 앱 종류: **비게임**
- [ ] 카테고리·소개·고객센터 이메일: `console-text.md` 그대로
- [ ] **로고**: `store-assets/icon-600.png`
- [ ] **썸네일**: `store-assets/thumbnail-1932x828.png`
- [ ] **세로 스크린샷** 3장 이상: `screenshot-1-home.png`, `screenshot-2-focus.png`, `screenshot-3-sleep.png`, `screenshot-4-stats.png`
- [ ] **가로 스크린샷**(칸이 있으면): `screenshot-landscape-1504x741.png`

**이렇게 보이면 성공:** 저장 후 앱 목록에 "몰입각"이 보여요.
**막히면:**
- ⚠ 썸네일 크기 오류 → `thumbnail-1100x800.png`로 바꿔서 올려요(문서와 실제 규격이 다르다는 보고가 있어 둘 다 만들어 뒀어요).
- 콘솔이 다른 크기를 요구하면 그 숫자를 Claude에게 알려줘요 → 바로 다시 만들어 줘요.
- 개인정보처리방침 주소를 요구하면 Claude에게 말해요(몰입각은 개인정보를 모으지 않아요. 안내 페이지를 만들어 줄 수 있어요).

---

## 6단계. 내 컴퓨터에서 빌드하고 점검 (5분)

**할 일** — 터미널(`study-beat` 폴더 안)에서:
```bash
npm run build
npm run check:toss
```

**이렇게 보이면 성공:**
- `npm run build` 마지막에 `앱인토스 빌드가 완료되었습니다. (molip-gak.ait)`
- `npm run check:toss` 마지막에 `✅ 모두 통과!` 또는 `✅ 업로드·QR 테스트 가능! ⚠️ 1개는 검수 요청 전에 바꾸세요.`
  (⚠️ 1개 = 배너 광고가 아직 테스트 ID라는 뜻. 8-1단계에서 실제 ID로 바꿔요.)

**막히면:** ❌ 줄 바로 아래 `→` 설명대로 해요. 모르겠으면 ❌ 줄을 복사해서 Claude에게 보내요.

---

## 7단계. 테스트용으로 올리기 (샌드박스) (15분)

**할 일**
1. 콘솔에서 **API 키**를 발급받아요(앱 설정 또는 워크스페이스 설정의 "API 키" 메뉴). 키는 비밀번호처럼 남에게 보여주지 않아요.
2. 터미널에서:
   ```bash
   npx ait token add
   ```
   키를 물어보면 붙여 넣고 Enter. (한 번만 하면 컴퓨터에 저장돼요.)
3. 업로드:
   ```bash
   npm run deploy
   ```
   - 다른 방법: 콘솔 화면에서 `molip-gak.ait` 파일을 직접 끌어다 올려도 돼요. 파일은 `study-beat` 폴더 안에 있어요.
4. 콘솔에 나온 **QR 코드**를 휴대폰 기본 카메라로 찍고, 뜨는 링크를 눌러 토스 앱에서 열어요.

**이렇게 보이면 성공:** 휴대폰 토스 앱 안에서 몰입각 홈 화면(오늘 목표 링, [25분 집중하기])이 열려요.
**막히면:**
- `intoss://molip-gak` 주소는 **출시 전에는 안 열려요.** 반드시 QR(테스트 주소)로 열어요.
- 검은 화면만 나오면 → 6단계를 다시 하고 다시 올려요. 그래도 같으면 Claude에게 알려줘요.

---

## 8단계. 휴대폰 점검표 (30분, 아이폰·안드로이드 각각)

하나라도 ❌이면 **화면을 캡처해서 Claude에게** 보내요. 고친 뒤 6단계부터 다시 해요.

**화면·이동**
- [ ] 맨 위에 **토스 내비게이션 바**(로고·몰입각·⋯·✕)가 있고, 그 아래 화면 안에 `‹` 버튼이 **또 보이지 않아요**
- [ ] 하위 화면(예: 수면)에서 토스 바의 뒤로 → 이전 화면으로
- [ ] **홈 화면에서 뒤로 → 미니앱이 닫혀요**(확인 창 없이)
- [ ] 두 손가락으로 벌려도 **확대가 안 돼요**
- [ ] 수면 화면도 **밝은 색**이에요
- [ ] ⋯ 버튼의 **공유·신고**가 동작해요

**소리** (이어폰 착용)
- [ ] [25분 집중하기] → [집중 시작] → 소리가 **부드럽게** 시작돼요(뚝 끊기거나 지지직 없음)
- [ ] 집중 중 [🎚 소리 바꾸기] → "🔈 스피커용"으로 바꾸고 이어폰을 빼도 소리가 나요
- [ ] 화면을 잠가도 소리가 계속 나요 — 안 되면 결과만 적어 두세요(기기에 따라 다를 수 있어요)
- [ ] **화면 꺼짐 비트 시험 (블루투스 이어폰이 있으면 꼭):** 설정 → 집중 이탈 감지를 잠깐 끄고 → [25분 집중하기] → [집중 시작] →
      소리가 들리면 **바로 화면을 꺼요** → 25분 동안 가끔 들어 봐요.
  - 성공: 끝날 때까지 좌우가 살짝 다른 "웅—" 하는 비트가 그대로, **1초에 10번 뚝뚝 끊기는 소리 없음**, 비트만 사라지는 일 없음
  - 끝나면 설정 → **소리 진단** 화면을 캡처해 두세요(문제가 있었다면 Claude에게 보내기). 시험 후 집중 이탈 감지는 다시 켜요.

**기록**
- [ ] 집중 중 홈 버튼으로 다른 앱에 갔다 오면 "집중 이탈" 안내가 나와요
- [ ] 집중을 끝내면 기록 탭에 시간이 쌓여요
- [ ] 토스 앱을 완전히 껐다 켜도 **기록과 내 믹스가 남아 있어요**

**광고** (테스트 광고 ID로 확인 — 광고를 여러 번 누르지 않아요)
- [ ] 홈·기록 화면 **맨 아래**에 광고 배너가 보여요(광고가 없으면 빈칸 없이 사라져요)
- [ ] 집중·수면·휴식 화면, 사운드 탭에는 광고가 **없어요**
- [ ] 설정 → 소리 진단 → "광고 배너: 테스트 ID · 표시됨"

**바로가기(인앱 기능)** — 선택
- [ ] QR 테스트 주소 끝에 `/focus`, `/sleep`, `/relax`를 붙여 열어 봐요 → 해당 화면으로 바로 가면 성공
- [ ] **열린 것만** 콘솔 "인앱 기능"에 `console-text.md`의 주소로 등록해요(등록했는데 안 열리면 반려돼요). 하나도 안 열리면 등록하지 않아도 돼요.

---

## 8-1단계. 인앱 광고 신청 → 실제 광고 ID로 바꾸기 (20분 + 기다리기)

**할 일**
1. 콘솔 → 나의 워크스페이스 → 정보 → **정산 정보** 등록(본인 명의 통장 사본 필요).
2. 콘솔 → 몰입각 → **인앱 광고** → 광고 사용 **신청**.
   - "앱 정보 승인 후 등록해 주세요"가 뜨면: 9단계에서 **앱 정보만** 먼저 검토 요청 → 승인되면 여기로 돌아와요.
3. **광고 그룹 만들기** → 종류 **배너 - 리스트형** → 만들어진 **광고 그룹 ID**를 복사해요(테스트 ID가 아닌 실제 ID).
4. 그 ID를 Claude에게 보내요 → Claude가 바꿔 넣은 새 `molip-gak.ait`를 받아 7단계처럼 올려요.
   - 직접 바꿀 때: `.env`의 `VITE_TOSS_AD_BANNER_ID=` 뒤를 그 ID로 바꾸고 6단계(`npm run build`, `npm run check:toss` → `✅ 모두 통과!`).

**이렇게 보이면 성공:** `npm run check:toss`에 `✅ 배너 광고: 실제 광고 그룹 ID (…)`.
**주의:** 새 광고 그룹 ID는 실제 광고가 나오기까지 **최대 2시간** 걸릴 수 있어요. 실제 ID로는 광고를 직접 누르거나 계속 새로고침하지 않아요(정책 위반).

---

## 9단계. 검수 요청 (5분 + 기다리기 2~3일)

**할 일:** 콘솔에서 앱 정보와 번들을 **검수 요청**해요. 번들은 **실제 광고 ID로 만든 버전**이어야 해요(8-1단계, `npm run check:toss`에 ⚠️ 없음).

**이렇게 보이면 성공:** 상태가 "검수 중"으로 바뀌어요. 결과는 이메일과 콘솔로 와요(영업일 2~3일).
**반려되면:** 반려 사유 문장을 **그대로 복사**해서 Claude에게 보내요 → 고친 코드를 받으면 2단계의 `git pull` → 6·7단계 → 다시 검수 요청.

검수는 4가지를 봐요: 운영(앱 정보·이미지), 기능(오류 없이 동작), 디자인(토스 화면 규칙), 보안.

---

## 10단계. 출시 🎉

**할 일:** 승인 메일이 오면 콘솔에서 **출시**를 눌러요.
**이렇게 보이면 성공:** 휴대폰에서 `intoss://molip-gak`을 열면(또는 토스 앱 검색에서 "몰입각") 앱이 열려요.

## 이미 반영해 둔 검수 기준 (참고)

| 기준 | 몰입각에서 한 일 |
|---|---|
| 비게임 WebView는 TDS(토스 디자인 시스템) 사용 | 버튼·스위치·바텀시트를 TDS로 |
| 라이트 모드 | 수면 화면을 밝은 라벤더로(토스판) |
| 토스 내비게이션 바, 뒤로가기 중복 금지, 홈에서 뒤로 → 종료 | 토스 안에서는 앱 자체 `‹` 숨김, 홈에서 뒤로 → 닫기 |
| 핀치 줌 금지 | 확대 막음 |
| 앱 이름 = 화면 제목 | 둘 다 "몰입각" |
| 외부 코드 실행(eval) 금지 | 없음(`check:toss`가 매번 확인) |
| 의료·과장 표현 금지 | 자동 검사(`npm test`, `check:toss`) |

⚠ 확인이 더 필요한 것: TDS를 어디까지 써야 통과인지(반려되면 범위를 넓혀요), 썸네일 실제 규격, 토스 뒤로가기와 바로가기 주소의 실제 동작(8단계에서 확인).
