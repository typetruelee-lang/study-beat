# Anima: Binaural Beats vs FOCUS CLAY — 비교와 차용 결정

조사 범위: Apple App Store·Google Play 등록 정보와 리뷰 요약(검색 결과 기준. 스토어 페이지 본문은 이 환경의 네트워크 정책으로 직접 열지 못함),
appbrain 요약, 사용자가 정리해 준 분석, 관련 논문. 화면·그래픽·문구는 **참고만** 했고 모두 새로 만들었다.

## 1. Anima 요약

| 구분 | 내용 |
|---|---|
| 핵심 기능 | 바이노럴 비트 + 아이소크로닉 톤, 자연음(비·바다·숲 등)과 섞인 "사운드스케이프", 모드별(집중·수면·명상·휴식·에너지) 추천 목록, 강도 조절, 타이머, 즐겨찾기, 백그라운드 재생 |
| 화면 느낌 | 어두운 배경 + 보라·파랑 그라데이션 오브(orb) 커버, 큰 원형 플레이어, 카드형 가로 스크롤 목록 |
| 사용자 반응(긍정) | 고르기만 하면 바로 재생, 자연음과 섞여 "삐-" 소리가 덜 거슬림, 디자인이 고급스러움, 수면용으로 자주 씀 |
| 사용자 반응(부정) | 구독 유도·잠금 콘텐츠가 많음, 백그라운드/화면 꺼짐 재생 끊김 보고, 어떤 주파수가 무엇인지 설명 부족, 일부 효과 문구 과장 |
| 과학적 근거 | 혼재. 메타분석에서 주의·불안·기억에 **작은~중간 효과**가 보고되나(Garcia-Argibay 2019, Psychological Research) 연구 간 편차가 크고, 최근 체계적 고찰은 뇌파 동조(entrainment) 근거가 일관되지 않다고 정리(Ingendoh 2023, PLOS ONE). 아이소크로닉 톤은 연구가 더 적다 |

## 3. FOCUS CLAY만의 차별점 (유지)

- **핵심 루프**: 10Hz + 배경음 + 25분 타이머 → 기록된 집중시간이 쌓임(공부 증명이 아님을 명시).
- 홈 첫 화면에 **오늘 목표 / 완료 / 남은 시간**과 [25분 집중하기].
- 집중 이탈 감지, 통계·나무, 루틴, 수면 페이드 종료.
- 소리마다 라이선스 메타데이터, 절차적 합성이라 저작권 부담 없음.
- 웹에서는 엔진만 떼어 다른 페이지에 넣을 수 있음(`/engine/`).

## 4. 아이소크로닉 톤 구현 메모

- 400Hz 기본 음을 비트 주파수로 켜고 끈다. 단순 사각파는 "딸깍" 소리가 나므로 고조파를 줄인 둥근 사각파(PeriodicWave 1·3·5차)로
  게이트를 열고 닫는다 → 스피커에서도 클릭 없음(`scripts/audio-check.mjs` 2a: 6·10·14Hz 엔벌로프 검출, 클릭 없음 확인).
- 좌우 같은 소리라 이어폰이 필요 없지만, 메타분석 대부분은 바이노럴 비트 연구다. 앱에서는 "스피커용"이라는 사용법만 말하고 효과를 따로 주장하지 않는다.
