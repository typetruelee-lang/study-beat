# 앱인토스 콘솔에 붙여 넣을 내용

콘솔의 칸 이름은 화면과 조금 다를 수 있어요. 비슷한 칸에 넣으면 돼요.
**굵은 글씨**는 꼭 그대로 써야 하는 값이에요.

## 기본 정보

| 콘솔 칸 | 넣을 내용 |
|---|---|
| 앱 ID / appName (영문) | **`molip-gak`** ← 한 번 정하면 못 바꿔요. 붙여 넣은 뒤 오타가 없는지 두 번 확인 |
| 앱 이름 | **`몰입각`** ← 앱 화면 제목과 같아야 해요 |
| 앱 종류 | 비게임 |
| 카테고리 | 생산성 · 교육 · 라이프스타일 중 고를 수 있는 것 (추천: 생산성) |
| 한 줄 소개 (부제) | 공부할 때 틀어두는 집중 사운드 |
| 고객센터 이메일 | 본인이 확인하는 이메일 주소 |

## 앱 소개 (긴 설명)

```
공부할 때 틀어두는 집중 사운드, 몰입각.

빗소리·카페·도서관 같은 배경음에 집중 사운드(바이노럴 비트)를 섞어 들으며
25분·50분·90분·2시간 타이머로 공부하고, 기록된 집중시간을 하루 목표와 함께 확인해요.

• 추천 사운드: "빗속 집중", "카페 몰입"처럼 미리 맞춘 조합을 한 번에
• 이어폰용·스피커용: 이어폰이 없어도 들을 수 있는 스피커용 모드
• 내 믹스 저장: 마음에 드는 소리 조합을 이름 붙여 저장
• 집중 이탈 감지: 집중 중 앱을 벗어나면 기록을 잠시 멈추고, 돌아오면 이어서
• 수면·휴식 모드: 잔잔한 소리와 최대 2시간 타이머(끝날 때 천천히 소리가 줄어들어요)
• 기록: 오늘·이번 주 집중시간, 하루 목표 달성률

모든 소리는 기기 안에서 만들어지고, 기록은 내 휴대폰에만 저장돼요.
몰입각은 공부·휴식·수면을 위한 배경 사운드 앱이에요. 의료기기가 아니며,
건강 상태를 진단하거나 개선하는 기능은 없어요.
```
