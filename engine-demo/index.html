몰입각 사운드 엔진

집중 사운드(Binaural Beat), 배경음, 노이즈를 섞어 재생하는 웹 엔진이에요. 이 페이지는 사용 예시이고, 아래 코드처럼 어떤 웹페이지에도 넣을 수 있어요.

🎧 집중 사운드는 이어폰·헤드폰으로 들어야 좌우 차이가 전달돼요. 의료 목적의 기능이 아니에요.

집중 사운드

배경음 · 노이즈

수면 타이머 끝나기 20초 전부터 천천히 줄어들어요.

내 페이지에 넣기

<script src="/engine/focus-clay-engine.js"></script>
<button id="start">집중 시작</button>
<script>
  const fc = FocusClay.create();
  fc.prewarm(['rain_01']);                 // 미리 준비 → 시작이 끊기지 않게
  document.querySelector('#start').onclick = () =>
    fc.play({ beat: 10, sounds: [{ id: 'rain_01', volume: 0.55 }], volume: 0.6 });
  // fc.setBeat(12)  fc.setBinaural(null)  fc.addSound('noise_pink', 0.4)
  // fc.setVolume(0.5)  fc.sleepTimer(30 * 60)  fc.stop()
  // FocusClay.sounds · FocusClay.presets 로 목록 확인
</script>
